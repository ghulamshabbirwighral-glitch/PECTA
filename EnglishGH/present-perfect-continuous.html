Present Perfect Continuous Tense

1. Definition (تعریف)

Def: Used to express actions that started in the past and are still continuing in the present.

تعريف: یہ ایسے کام کو ظاہر کرتا ہے جو ماضی میں شروع ہوا ہو اور موجودہ وقت میں بھی جاری ہو۔ اردو پہچان: جملے کے آخر میں 'رہا ہے'، 'رہی ہے'، 'رہے ہیں' کے ساتھ وقت کا ذکر یا تعیّن ہوتا ہے۔

2. Positive Sentences (مثبت جملے)

Formula: Subject + has been / have been + V1-ing + Object + since / for + Time

Rule (Urdu): He, She, It, Single Name کے ساتھ **has been** اور I, We, You, They, Plural کے ساتھ **have been** استعمال ہوتا ہے۔ فعل کی پہلی فارم کے ساتھ **ing** کا اضافہ کیا جاتا ہے۔ مقررہ وقت (مقامِ آغاز جیسے morning, 8:00 AM) کے لیے **Since** اور غیر مقررہ وقت (مدت جیسے 2 hours, 1 hour) کے لیے **For** استعمال ہوتا ہے۔

3. Negative Sentences (منفی جملے)

Formula: Subject + has / have + not + been + V1-ing + Object + since / for + Time

Rule (Urdu): منفی جملہ بنانے کے لیے **has** یا **have** کے فوراً بعد اور **been** سے پہلے **not** لگایا جاتا ہے (مثلاً: has not been / have not been)۔

4. Interrogative Sentences (سوالیہ جملے)

Formula: Has / Have + Subject + been + V1-ing + Object + since / for + Time?

Rule (Urdu): سوالیہ جملہ بنانے کے لیے **Has** یا **Have** کو جملے کے شروع میں لکھا جاتا ہے، پھر **Subject** کے بعد **been** لگایا جاتا ہے اور آخر میں سوالیہ نشان (?) آتا ہے۔
